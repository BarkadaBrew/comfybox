## Risks And Missing Work

1. **Major, §3/§4 Prompt Relay**: Claim: per-segment prompt conditioning is “not present anywhere” and Phase 2 requires a new attention mask hook.
   Code: `beat_schedule` already implements PromptRelay-style token-range temporal attention bias (`Sources/ZImage/LTX2/LTX2BeatSchedule.swift:1-29`, `:258-300`) and threads it into transformer calls (`Sources/ZImage/LTX2/LTX2Pipeline.swift:1793-1812`, `:1931-1960`).
   Correction: Reframe WP7 as adapting Director prompt segments to the existing beat-schedule/bias system, plus gaps for chunk-spanning schedules and UI authoring, not as first implementation of temporal prompt conditioning.

2. **Major, §4.3 Persisted Queue**: Claim: director jobs can be recovered after crash like `generate`.
   Code: durable queue persists only `"generate"` and `"lora_swap"` (`Sources/ZImage/Server/QueuePersistence.swift:9-15`, `:21-27`); local video is explicitly refused during recovery because it is non-persisted (`Sources/ZImage/Server/WarmServer.swift:3717-3728`).
   Correction: Add a dedicated work package for serializable, recoverable video/director job state. “Queue kind + recovery” is not a small add-on to WP2.

3. **Major, §4.2 Audio**: Claim: audio inpainting is blocked on confirming an audio VAE encoder.
   Code: encoder exists (`Sources/ZImage/LTX2/VAE/LTX2AudioVAE.swift:304-339`) and loads encoder weights (`:371-389`), but only generated noise audio is wired (`Sources/ZImage/LTX2/LTX2Pipeline.swift:487-504`).
   Correction: The real missing package is imported audio ingest: AVAssetReader decode/resample/mix, waveform→mel preprocessing, `LTX2AudioVAE.encode` normalization/patchify parity, and an audio-latent noise mask/update path.

4. **Major, §4.2 Retake**: Claim: retake requires a new temporal noise mask.
   Code: per-frame denoise masks already exist and are restored before/after steps (`Sources/ZImage/LTX2/LTX2Conditioning.swift:27-29`; `Sources/ZImage/LTX2/LTX2Pipeline.swift:1869-1902`, `:2079-2085`, `:2178-2183`).
   Correction: The missing work is not the mask primitive; it is base-video decode→VAE encode, construction of clean latent for frozen spans, time-range mask authoring, and seam validation.

5. **Major, §3 Production Recipe**: Claim: current production recipe is euler, 10-step, NAG 5/0.25/2.5, STG 0.3 flat, color anchor 1, audio on via resolver.
   Code: resolver builtins are not that recipe (`Sources/ZImage/LTX2/LTX2ConfigResolver.swift:61-96`); audio is request-level (`Sources/ZImage/LTX2/LTX2VideoGenerator.swift:157`; Desktop default true at `Sources/ComfyBoxDesktop/EngineService.swift:1870-1872`).
   Correction: Say Director honors the same request/preset/config/env/builtin resolver stack; do not bake a single recipe into §3 unless citing the config/preset source that sets it.

6. **Minor, §4.2 Imported Audio Mux**: Claim: imported mode is pure post-processing because `LTX2PostProcess` already muxes.
   Code: `writeMP4` muxes PCM `AudioTrack`, not file-path audio clips (`Sources/ZImage/LTX2/LTX2PostProcess.swift:271-306`, `:385-409`, `:463-488`).
   Correction: Add a Phase 1 work item for audio file decode, timeline mixing, resampling, duration trim/pad, and generated-audio suppression.

7. **Minor, §5 WP2 Size**: Claim: WP2 can include keyframe wire, compiler, routes, queue recovery, trace plan, generated/imported audio.
   Code: current `LTX2VideoRequest` and `LocalVideoRequest` are single-image schemas (`Sources/ZImage/LTX2/LTX2VideoGenerator.swift:31-99`; `Sources/ZImage/Server/WarmServer.swift:2267-2391`), while local video recovery is non-durable.
   Correction: Split WP2 into engine/wire keyframes, Director compiler, Director routes/status orchestration, imported-audio post, and durable job recovery.

8. **Nit, §3 Not Present List**: Claim: “temporal masks” are absent.
   Code: temporal denoise masks exist (`Sources/ZImage/LTX2/LTX2Conditioning.swift:27-29`).
   Correction: Say “no retake time-range mask API or compiler,” which is accurate.
